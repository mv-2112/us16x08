# Find a problem with Diagnostics

Open **Window → Diagnostics Log** (⌥⌘L). It lists everything sent to the unit and every error.
- **Copy All** puts a header (app, macOS, device, firmware, sample rate, meter state) plus the log on the clipboard — paste it into a bug report.
- **Save…** writes the same to a file.
- If the app is using a lot of CPU, run Activity Monitor → *Sample Process* and attach the result.
