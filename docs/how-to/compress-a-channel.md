# Compress a channel

1. Select the channel and switch the compressor **On** (or the strip's **COMP** chip).
2. Set **THRESHOLD** (−32…0 dB): the level above which compression starts. Drag the node on the graph or the knob.
3. Set **RATIO** (1:1 … 16:1, ∞:1). Higher = flatter above the threshold.
4. Set **ATTACK** (2–200 ms) and **RELEASE** (10–1000 ms).
5. Set **GAIN** (0–20 dB) to make up lost level.

**Reading the display**
- The big graph is input level against output level (−48…0 dB on both axes, labelled). Threshold, ratio and gain all move the curve.
- The small sketch beneath shows how a loud burst is clamped (attack) and recovers (release).
- The orange bar to the right is live gain reduction from the unit (0–24 dB).

At threshold 0 dB, ratio 1:1 the compressor does nothing, which is the default.
