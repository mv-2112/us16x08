# Use Mixer True Bypass

Use the **True Bypass** switch at the top right of the window (or the **BYPASS** chip on the master strip, which does the same thing).

While it is on, the unit matches input to output directly, so **PHASE, EQ, COMP and the docked EQ/compressor panel are disabled** and
marked *Bypass*. Mute and faders stay available in the panel but remember the unit is skipping its mixer processing.
The switch is disabled when the unit is disconnected because it lives in the unit.

See [Mute, bypass and what the unit does](../explanation/bypass-and-mute.md).
