# Route outputs

1. Open **Routing**.
2. For each of the eight line outputs choose a source (master L/R, or computer outputs 3–10).
3. **Computer out → Stereo Bus** (on by default) feeds computer playback into the master mix. Switch it off to keep playback out of the mix. It needs the unit connected.

Power-on routing: outputs 1–2 = master L/R, outputs 3–8 = computer 3–8.
