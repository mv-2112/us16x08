# Meters

- LED ladder, −48…0 dBFS in 2 dB segments: **green** to −12, **yellow** −12…−6, **red** above −6.
- **Peak hold:** one lit segment, held 1.5 s then falling 20 dB/s.
- **Clip lamp:** above the ladder; latches when the raw level reaches 32700 (≈ −0.02 dBFS). Click any meter or press PEAKS to clear.
- **Gain reduction:** orange bar beside the compressor graph, 0–24 dB.
- Meters run whenever the unit is connected (about 50 polls/s, redrawn at 30 fps). They show whatever the unit reports; whether that is pre- or post-fader is not yet established.
- Calibration: 0x7FFF = full scale; see [Meters, peaks and calibration](../explanation/meters.md).
